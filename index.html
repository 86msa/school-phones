تفعيل الحفظ على GitHub

  1. افتح صفحة إنشاء توكن في GitHub.
  2. اختر اسمًا ومدة صلاحية. في Repository access اختر Only select repositories ثم school-phones.
  3. في Permissions → Repository permissions اجعل Contents = Read and write.
  4. اضغط Generate token، انسخه والصقه هنا.
